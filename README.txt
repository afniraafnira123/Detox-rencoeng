DETOX RENCOENG — Web + CMS

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html untuk melihat website.
3. Buka admin.html untuk masuk ke panel penjual.
4. Password awal: admin123.

EDIT & DOWNLOAD:
- Edit teks/gambar di admin.html.
- Klik "Simpan Semua Perubahan".
- Klik "⬇ Download Website Hasil Edit".
- Browser akan mengunduh DETOX_RENCOENG_Web_Hasil_Edit.zip.
- Ekstrak ZIP hasil download lalu buka index.html.
- Hasil edit dibawa ke dalam app.js sehingga website hasil download tetap menampilkan perubahan.

Catatan:
- CMS ini masih berbasis browser/localStorage.
- Tombol download membuat paket website statis hasil edit.
- Untuk admin online multi-perangkat dengan database/login sungguhan, diperlukan backend dan hosting.
